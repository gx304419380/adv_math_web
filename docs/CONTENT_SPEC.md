# 内容规范

配合 [PRINCIPLES.md](PRINCIPLES.md) 使用。写新章节前先读核心原则。

## 1. 单章页面：8 个固定区块

顺序不得改动，缺一不可：

| # | 区块 | 内容 |
|---|---|---|
| ① | 章节头 | 章号、册别、标题、副标题、预计时长、演示数、进度徽标（由 `nav.js` 填） |
| ② | 学习目标 | 3–5 条可勾选目标，写「学完能做什么」，不写「了解/掌握」这类空话 |
| ③ | 知识结构图 | AntV G6，展示本章知识点依赖与通往下一章的出口 |
| ④ | 逐节讲解 | 按教材节序，每节见下方结构 |
| ⑤ | 常见误区 | 3–5 条，每条写「错误做法 + 为什么错 + 正确做法」 |
| ⑥ | 习题与自测 | 纸笔练习（折叠答案）+ 交互选择题（即时判定与解析） |
| ⑦ | 小结 | 三五句话串起全章 + 上一章/下一章导航 |
| ⑧ | 页脚 | 固定「非官方学习辅助」声明、参考书目、免责声明链接，**每页显著可见** |

## 2. 每一节的建议结构

```
原创引入（生活类比 / 一个让人愣住的问题）
  → 定义或定理（语义卡片，带编号）
  → 函数图像 / 交互演示（data-demo 挂载，图下必须有解读）
  → 直观理解（几何意义、一笔画、类比）
  → 例题（题目 / 解 / 评注 三段式）
  → 推导或性质（需要时折叠展示）
  → 常见误区（该节特有的坑）
```

不是每节都必须凑齐全部，但**「讲解 + 至少一张图 + 图下解读」是硬要求**。

## 3. 怎样「尽可能贴近教材」

对齐的是**体系**，不是文字：

- 章节顺序、节名、知识点名称沿用同济《高等数学》第七版上下册 12 章（见 [PROJECT_PLAN.md](PROJECT_PLAN.md)）。
- 数学术语用教材规范说法：去心邻域、左/右极限、无穷小的阶、等价无穷小、第一类/第二类间断点、元素法……不要自造别名。
- 符号约定统一：\(x\to x_0^+\)、\(\lim\limits_{n\to\infty}\)、\(\infty\) 不参与四则运算。
- **定义与定理体系要完整**：不仅讲主结论，还要覆盖唯一性、局部有界性、局部保号性、单侧极限、存在准则、运算性质、边界条件等教材会列出的配套结论。
- 先修关系与章间衔接要在知识图、小结、章末预告里体现。
- 站内「定义 1.1」「定理 1.8」等编号是**本站自用编号**，不是教材原编号；页面需明示，避免学生对照时混淆。

## 4. 原创边界（逐章自检清单）

- [ ] 不含教材正文段落、例题、习题题干、题号、答案、原图、表格、版式、扫描页
- [ ] 讲解文字全部自撰；例题数据、自测题全部自编
- [ ] 所有图形/动画/SVG 由 `plot.js`、原生 SVG、CSS 或 three.js 原创绘制
- [ ] 页脚含「非官方学习辅助」+ 参考书目 + 免责声明链接
- [ ] 无「习题 x-y」「原书图」「见教材第 n 页」等触发词（`check.sh` 会扫描）
- [ ] 不提供任何教材 PDF 或扫描件下载
- [ ] 存疑段落一律重写，不抱侥幸

**注意**：数学定义、定理、公式是客观事实，可以且应当准确表述；受版权保护的是教材的文字表达与编排。做法是用自己的话完整重讲，而不是删掉知识点。

## 5. 讲解语言

- 一段只讲一件事；长推导拆成编号步骤（`.derive`），每步配一句「这一步在做什么」。
- 术语首次出现 `<strong class="term">`，当场给一句白话解释。
- 该记住的结论 `<mark class="key">`，每节不超过 2–3 处，避免满屏高亮。
- 用第二人称「你」，像助教在旁边讲；不用「读者」「学生应」这类公文腔。
- 公式用 KaTeX：行内 `\( ... \)`，独立 `$$ ... $$`；需要编号时用 `.formula-box`。
- **不要用 `<code>` 包裹公式**（KaTeX 会跳过 code 标签）。

## 6. 交互演示规范

- 页面里用 `<div class="demo-box" data-demo="名称">` 挂载，实现写在本章 `demo.js`，注册进 `DEMOS` 表。
- 优先复用共享能力：`AM.Plot`（Canvas 坐标系/曲线/点/区域）、`AM.StepController`（分步动画）、`PLOT_COLORS`（统一配色）、`AM.mountGraph`（JSXGraph）。
- 每个演示必须有：标题、一句操作说明、可拖动/可播放的控件、随参数更新的数值解读（`.readout`）。
- 演示数量写进 `chapters.json` 的 `demos` 数组，首页卡片会显示。
- 三维内容（第 8–11 章）用 three.js，移动端限制 `pixelRatio`、切页 `dispose()`，低配降级为静态 SVG。

## 7. 自测题

- 题干、选项、解析全部自编；解析要解释「为什么对」和「为什么其他选项错」，不能只报答案。
- 交互题写在 `<div data-mount="quiz">` 内的 `<script type="application/json">`，字段 `q / options / answer / explain`。
- 纸笔题用 `.exercise-card` + `<details class="ex-answer">`，适合先自己算再看答案。
