## 逐章标准化 9 步循环

1. 对照 `chapters.json.sections` 核对知识点名称与顺序（只对齐名称）
2. 过一遍 [CONTENT_SPEC.md](CONTENT_SPEC.md) 的原创边界自检清单
3. 写原创讲解、定义/定理体系、自编例题（KaTeX）
4. 写 `chXX/demo.js` 与 `figures/*.svg`，复用共享绘图与动画组件
5. 从 `chapters/_template/chapter.html` 组装页面，挂 `data-demo`
6. `python3 tools/shot.py --chapter chXX` 本地截图（自动起服务）
7. `bash tools/check.sh` 静态校验 + sympy 公式复核
8. 提交 `feat(chNN): …`
9. 把该章 `status` 改为 `done`，跑 `python3 tools/sync-chapters.py` 同步 `chapters.js`，首页进度看板自动刷新

每批结束跑一次全站 `check.sh` + 截图回归。
