# 文档索引

这个文件夹是**仓库的维护契约**。任何人（包括未来的自己、其他贡献者、AI 助手）在改动本仓库之前，都应先读 `PRINCIPLES.md`，再按对应文档执行。

| 文档 | 讲什么 | 什么时候读 |
|---|---|---|
| [PRINCIPLES.md](PRINCIPLES.md) | **最高原则**：把学生当零基础来教、能加图就加图、能放动画就放动画、纯静态零门槛、基于教材但不复制 | 每次动手前，必读 |
| [VISUAL_SPEC.md](VISUAL_SPEC.md) | 视觉规范：设计 token 的唯一来源、语义组件表、页面骨架、响应式、禁止事项 | 改样式、做新组件时 |
| [CONTENT_SPEC.md](CONTENT_SPEC.md) | 内容规范：单章 8 区块、每节结构、如何贴近教材、原创边界、讲解语言 | 写新章节内容时 |
| [PROJECT_PLAN.md](PROJECT_PLAN.md) | 12 章清单、分批计划、当前进度、逐章生产流程与验收门槛 | 排期、接手新章节时 |
| [MAINTAINER_GUIDE.md](MAINTAINER_GUIDE.md) | 技术架构、`file://` 兼容规则、脚本加载顺序、新增一章的操作步骤、验收与部署 | 改代码、提交、部署时 |

## 一句话

> 这是一个**给完全不懂的学生看的**、**纯静态的**、**双击 `index.html` 就能学**的高等数学图解站；它以同济《高等数学》第七版为骨架，但所有讲解、图形、动画、题目都是原创。

## 给普通用户的话（不要写进技术文档里）

普通学习者**不需要看这个文件夹**，也不需要命令行、不需要安装任何东西、不需要启动服务器。直接用浏览器打开仓库根目录的 `index.html` 即可。详见 [README.md](../README.md)。
