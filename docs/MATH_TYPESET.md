# 数学排版规范

> **本文件是硬性规定，不是建议。** 违反任何一条都算 bug，需在合并前修掉。
> 一句话原则：**读者看到的必须是排好版的数学，而不是 TeX 源码，也不能是风格不统一的“差不多”。**

相关文件：`assets/js/math.js`（渲染入口 + 自动审计）、`assets/css/base.css`（`--math-*` 变量与 `.katex` 规则）、[VISUAL_SPEC.md](VISUAL_SPEC.md)。

## 0. 技术底座

| 项 | 规定 |
|---|---|
| 渲染引擎 | KaTeX 0.16.x，通过 CDN 加载，版本号只在 `assets/js/cdn.js` 里写一次 |
| 定界符 | 行内 `\( … \)`，独立公式 `$$ … $$`。**不使用** `$ … $`（易与正文美元符号/编程内容混淆） |
| 渲染时机 | `initMath()` 在 `boot.js` 中全局执行一次；新增内容后需再次调用 |
| 渲染失败 | 必须**降级成可读文本**并给出提示，绝不允许白屏或裸露反斜杠 |

## 1. 该斜体的斜体、该正体的正体（最高频错误）

数学排版的核心规矩：**变量斜体，一切“不是变量”的东西正体。** KaTeX 默认已处理大部分，出问题的是我们手写的部分。

### 必须斜体（不用写任何命令，默认就是斜体）

单字母变量、函数名中的自定义部分、点、下标里的变量索引：

| 场景 | 写法 | 渲染 |
|---|---|---|
| 变量 | `x`、`y`、`t` | *x*、*y*、*t* |
| 函数 | `f(x)`、`g(t)` | *f*(*x*) |
| 数列项 | `a_n`、`S_n` | *a*ₙ |
| 变量下标 | `x_i`、`a_{n+1}` | *x*ᵢ |
| 希腊变量 | `\alpha`、`\varepsilon`、`\theta` | *α*、*ε*、*θ* |
| 增量 | `\Delta x`、`\Delta y` | Δ*x*（Δ 自动正体，x 斜体，正确） |

### 必须正体（需要显式命令）

| 类别 | 正确写法 | 错误写法 | 说明 |
|---|---|---|---|
| 函数名 | `\sin x`、`\ln x`、`\lim`、`\max` | `sin x`、`ln x` | 不写反斜杠会变成 *s·i·n·x* 四个变量相乘 |
| 已定义的算子 | `\log`、`\exp`、`\det`、`\gcd` | `log`、`exp` | 同上 |
| 微分 d | `\mathrm{d}x` | `dx` 或 `d x` | 严格排版中 d 为正体，与变量 x 区分；本站统一用 `\mathrm{d}` |
| 自然常数 e | `\mathrm{e}^x` | `e^x` | ISO 80000-2 规定 e 正体 |
| 虚数单位 i | `\mathrm{i}` | `i` | 同上 |
| 圆周率 π | `\pi` | `\Pi` | `\pi` 已是正体风格，无需额外处理 |
| 单位 | `\mathrm{m/s}`、`5\,\mathrm{cm}` | `5 cm` | 数字与单位间加 `\,` 细空格 |
| 多字母标识符 | `\mathrm{d}x`、`\mathrm{d}y` | `dx`（会渲染成 *d*·*x*） | 多字母缩写一律 `\mathrm` |
| 文字说明 | `\text{当 } x\to 0 \text{ 时}` | `当 x\to 0 时` | 中文直接进公式会被当成斜体变量，几乎必然出错 |

> **判断口诀**：这个名字是“数学对象的名字”还是“一个变量的符号”？对象名 → 正体；变量 → 斜体。

### 常用对照速查

```
✅ \lim_{x\to 0}\frac{\sin x}{x}=1
✅ f'(x)=\lim_{\Delta x\to 0}\frac{f(x+\Delta x)-f(x)}{\Delta x}
✅ \int_a^b f(x)\,\mathrm{d}x
✅ \mathrm{e}^{x}=\sum_{n=0}^{\infty}\frac{x^n}{n!}
✅ \frac{\mathrm{d}y}{\mathrm{d}x}
❌ lim_{x->0} sin x / x = 1          （lim、sin 未正体，箭头用了 ->）
❌ \int_a^b f(x) dx                   （微分 d 未正体，且缺细空格）
❌ e^x = Σ x^n/n!                     （e 未正体，用了 Unicode Σ）
```

## 2. 不许出现“原始写法”

以下任何一项出现在**最终渲染页面**上都算违规：

| 违规现象 | 例 | 原因与修法 |
|---|---|---|
| 裸露的 TeX 命令 | 页面上出现 `\frac{a}{b}`、`\lim` | 定界符没包住 / 渲染失败。修：检查 `\( \)` 是否配对 |
| 裸露的定界符 | 页面上出现 `$$`、`\(` | HTML 转义把 `\)` 吃掉了，或跨了 `<p>` 标签边界。**公式不要跨块级标签** |
| HTML 实体混入公式 | `\varepsilon&gt;0` | 应为 `\varepsilon>0`（KaTeX 内部已处理 `>`，源码里写 `&gt;` 会原样显示）。**中文正文里用 `&lt;` `&gt;`，公式里用 `<` `>`** |
| Unicode 数学符号 | `Σ`、`∫`、`√`、`≤`、`α`、`∞` | 字体依赖重、缩放不一致。一律换成宏：`\sum`、`\int`、`\sqrt`、`\le`、`\alpha`、`\infty` |
| 用斜杠代替分式 | `x^2/2` | 行内可接受（如 `\tfrac{x^2}{2}` 更好），独立公式必须 `\frac` |
| 用 `->` 表示箭头 | `x -> 0` | 必须 `\to` 或 `\rightarrow` |
| 用 `*` 表示乘号 | `a * b` | 必须 `a\cdot b` 或 `ab`；叉乘用 `\times` |
| 中文句号进公式 | `\text{成立。}` | 标点放公式外，公式内只留必要的空格 `\quad` |

### 中文与公式的边界

**中文不进公式本体，只允许出现在 `\text{}` 里。** 推荐把中文全部移到公式外的正文：

```html
<!-- ✅ 好：条件说明放正文，公式只放数学 -->
<p>当 \(x\to 0\) 时，\(\frac{\sin x}{x}\to 1\)。</p>

<!-- ✅ 也可以：数量少时用 \text -->
$$\lim_{x\to 0}\frac{\sin x}{x}=1 \quad (\text{第一个重要极限})$$

<!-- ❌ 坏：中文裸奔进公式 -->
$$\lim_{x\to 0}\frac{\sin x}{x}=1 \quad (第一个重要极限)$$
```

公式与中文之间**必须有空格**：写成 `函数 \(y=f(x)\) 的图像`，不要写成 `函数\(y=f(x)\)的图像`——后者在渲染后会贴在一起。

## 3. 公式编号与引用

| 规定 | 说明 |
|---|---|
| 编号格式 | `(1.1)`、`(1.2)` —— 章号.序号，与教材习惯一致 |
| 编号位置 | 右侧对齐，放在 `.formula-box` 的 `.fb-no` 元素 |
| 引用写法 | 正文写“由式 (1.1)”或“见式 (1.3)”，**不要**写“见上面那个公式” |
| 编号连续 | 同一章内从 1 开始连续，不跳号、不重复 |
| 非关键公式 | 不编号。**每章编号公式控制在 5–12 个**，多了就失去“重点”的作用 |

```html
<div class="formula-box">
  <span class="fb-no">(1.1)</span>
  $$\lim_{x\to x_0}f(x)=L \iff \forall\,\varepsilon>0,\ \exists\,\delta>0:\ 0<|x-x_0|<\delta \Rightarrow |f(x)-L|<\varepsilon$$
</div>
```

## 4. 排版细节（间距与断行）

| 场景 | 写法 | 别写成 |
|---|---|---|
| 公式内分隔多行 | `\quad`（宽）、`\qquad`（更宽） | 一堆空格 |
| 数字与单位 | `5\,\mathrm{cm}` | `5cm` |
| 微分与函数 | `f(x)\,\mathrm{d}x` | `f(x)dx` |
| 省略号 | `\cdots`（居中，用于加法/乘法）、`\dots`（基线，用于列表） | `...` |
| 集合与逻辑 | `\in`、`\subset`、`\forall`、`\exists` | ∈、⊂、∀、∃ |
| 绝对值 | `\left|x\right|` 或 `|x|` | `\mid x \mid`（当分隔符用时才用 `\mid`） |
| 自适应括号 | `\left(\frac{a}{b}\right)` | `(\frac{a}{b})`（括号会太矮） |
| 极限位置 | 独立公式 `\lim_{x\to 0}`（下标在下方）；行内 `\lim\limits_{x\to 0}` 需要下方位置时加 `\limits` | 行内直接写导致下标挤到右下角 |
| 分段函数 | `\begin{cases} … \end{cases}` | 用表格拼 |
| 矩阵 | `\begin{pmatrix} … \end{pmatrix}` | 用空格对齐 |

### 什么时候不用独立公式

- 只有一个符号或极短表达式（如 `\(x>0\)`）→ 用行内
- 结论性的、需要编号的、多行推导的 → 用独立公式
- **连续三行以上都是独立公式** → 考虑改用 `.derive-list` 分步推导组件（带“为什么”注释，见 [CONTENT_SPEC.md](CONTENT_SPEC.md)）

## 5. 全局样式：只在一处改

公式的字号、间距**不允许**在各章页面里写死。全部由 `assets/css/base.css` 的 `:root` 控制：

```css
--math-inline-scale: 1.06;   /* 行内公式相对正文字号 */
--math-display-scale: 1.14;  /* 独立公式相对正文字号 */
--math-display-gap: .9rem;   /* 独立公式上下留白 */
```

| 需求 | 做法 |
|---|---|
| 全站公式偏小 | 改 `--math-inline-scale` / `--math-display-scale` 一处即可 |
| 某章公式特别长 | 用 `.formula-box`（自带横向滚动），**不要**缩小字号 |
| 移动端 | 已在 `@media (max-width: 640px)` 里把独立公式降到 1em，长公式横向滚动，不缩字 |
| 禁止 | 在 HTML 里写 `style="font-size:..."` 覆盖公式；在章节 CSS 里重定义 `.katex` |

## 6. 涉及图形的数学标注

JSXGraph / Canvas 里的坐标轴标签、点标签同样是“排版”的一部分：

- 变量标签斜体：`x`、`y`、`f(x)`
- 中文标签不要塞进 canvas 文字里（不能换行、字体渲染差），改用 HTML 的 `.demo-caption` 说明
- 刻度值正体数字，与坐标轴保持 6–8 px 间距
- 公式形式的标签用 KaTeX 渲染后转 SVG 或直接放在图旁的 HTML 里，禁止在 canvas 里手绘分数

## 7. 自动化守卫（已内置，别再靠肉眼）

`assets/js/math.js` 里的 `auditMath()` 会在页面加载后自动跑一遍，检出三类问题并在控制台警告：

| 检查项 | 触发条件 | 对应违规 |
|---|---|---|
| `raw-delimiter` | 文本节点里出现未被渲染的 `$$` 或 `\(` | §2 裸露定界符 |
| `cjk-in-math` | `.katex` 节点内出现汉字 | §1/§2 中文裸奔进公式 |
| `strict: 'warn'` | KaTeX 遇到不推荐写法 | 非规范排版 |

```js
// 手动复查（F12 控制台）
auditMath(document);
```

`tools/check.sh` 里另有静态检查：检测 `$` 单美元定界符、`\frac` 未配对大括号、Unicode 数学符号（`Σ ∫ √ ≤ ≥ α β ∞`）。

## 9. 运行时动态内容的公式（最容易漏的地方）

页面加载时 `initMath()` 只跑一次。**之后由 JS 动态插入的内容不会被自动渲染**，必须显式处理。
历史上正是这里漏掉了，导致按钮上出现 `x²`、读数里出现 `1/x` 这种假数学。

| 场景 | 正确做法 | 错误做法 |
|---|---|---|
| 按钮文字是数学 | `btnRow(el, [{ tex: 'x^{2}' }])` 或 `btn.appendChild(texInline('x^{2}'))` | `label: 'x²'` |
| 读数 / 状态文字 | `out.innerHTML = \`... ${texHTML('x^{2}')} ...\`` | 直接写 `x²`、`1/x` |
| 动态插入的整块 HTML | 插入后调用 `initMath(容器)` | 插入完就不管 |
| 自测题的题干 / 选项 / 解析 | 渲染后 `initMath(节点)`（`quiz.js` 已内置） | 以为首次渲染已覆盖 |
| Canvas 内文字 | 只写中文几何标注（"检验线""上边界"），数值放到图下的读数区 | 在 canvas 里写 `x=1.2`、`x^2` |

### 为什么 canvas 里不能写数学

Canvas 的 `fillText` 只能画字符串，无法表达上标、分数、斜体变量。硬写 `x^2` 或 `x²` 都是错的：
前者是源码，后者是 Unicode 字符，字体和基线都不受控。**正确做法是 canvas 只负责画图，
所有数学表达放到图下方的读数区，由 KaTeX 渲染。**

### 三个工具函数

| 函数 | 返回 | 用在哪 |
|---|---|---|
| `texInline(tex)` | DOM 元素 | 需要 appendChild 的地方（按钮、容器） |
| `texHTML(tex)` | HTML 字符串 | 模板字符串拼 `innerHTML` |
| `renderTexNodes(root)` | — | 批量渲染页面里所有 `[data-tex]` 元素 |

> 规则：**只要按钮/标签/读数的文字里含数学，就必须过这三个函数之一。** 直接写 Unicode 上下标（`² ³ ˣ ⁿ √`）视为违规。
