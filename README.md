# 高等数学 · 互动学习站

一个把同济大学《高等数学》（第七版）讲得更直观的**非官方学习辅助网站**：章节结构与知识点名称和教材对齐，讲解文字全部原创，配大量可拖动的示意图、分步动画和交互自测。

> ⚠️ 本站不是教材电子版，不含原书正文、例题、习题、原图或扫描页。详见 [DISCLAIMER.md](DISCLAIMER.md)。

## 为什么做这个

教材写得严谨，但很多概念（ε-δ、夹逼、黎曼和、曲面定向、级数收敛）光看静态文字很难建立直觉。这里把每一节都配上一个「能动手玩」的图：拖一拖 ε 条带看 δ 怎么变，拉一拉滑块看割线怎么逼近切线，转一转三维曲面看切平面。目的不是替代教材，而是帮你在读教材之前先把几何图像建立起来。

## 本地运行

纯静态站点，不需要安装依赖或构建：

```bash
bash tools/serve.sh          # 默认 http://localhost:8000
```

也可以直接用浏览器打开 `index.html`（公式与图形库走公共 CDN，需要联网）。

## 目录结构

```
index.html              首页：12 章卡片 + 进度看板
chapters.json           单一数据源：章节元数据
assets/css/             基础样式、布局、组件
assets/js/              共享模块：公式、图形、动画、导航、测验、主题
chapters/_template/     单章页面模板与元数据样例
chapters/chXX/          每章页面 + 交互脚本 + 原创 SVG
tools/                  本地预览、静态校验、公式复核、截图验收
```

新增一章：复制 `chapters/_template/chapter.html` 到 `chapters/chXX/chXX.html`，按模板的 8 个区块填内容，用 `[data-mount]` 挂上交互演示，再在 `chapters.json` 里登记即可。

## 技术栈

零构建，全部走公共 CDN：

- **KaTeX** — 公式渲染
- **JSXGraph** — 可拖动的函数图像与几何图形（第 1–7 章）
- **three.js** — 三维曲面与向量场（第 8–11 章，按需加载）
- **GSAP / CSS / 原生 SVG** — 分步动画与手绘示意图
- **Mermaid** — 每章知识结构图

CDN 版本统一在 `assets/js/cdn.js` 管理，加载失败会显示降级提示而不是白屏。
