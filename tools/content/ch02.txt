        <h3><span class="sec-badge">2.1</span>导数概念</h3>
        <p>开车时速度表显示的是「此刻多快」，可你用路程除以时间算出来的总是一段路的平均速度。把这段时间压得极短，平均速度就变成了瞬时速度——这个「把差商取极限」的动作，就是导数。</p>

        <div class="math-block definition">
          <div class="mb-head"><span class="mb-tag">定义</span><span class="mb-title">导数</span><span class="mb-no">2.1</span></div>
          <div class="mb-body">
            设 \(y=f(x)\) 在 \(x_0\) 的某邻域内有定义。当自变量有增量 \(\Delta x\)（\(\Delta x\neq 0\)）时，函数增量为 \(\Delta y=f(x_0+\Delta x)-f(x_0)\)。若极限
            $$f'(x_0)=\lim_{\Delta x\to 0}\frac{\Delta y}{\Delta x}=\lim_{\Delta x\to 0}\frac{f(x_0+\Delta x)-f(x_0)}{\Delta x}$$
            存在且为有限数，则称 \(f\) 在 \(x_0\) <strong class="term">可导</strong>，这个极限值叫 \(f\) 在 \(x_0\) 的<strong class="term">导数</strong>。
            <mark class="key">差商里 \(\Delta x\neq 0\)，所以永远不能直接把 0 代进去；要先化简，再取极限</mark>。
          </div>
        </div>

        <div class="math-block theorem">
          <div class="mb-head"><span class="mb-tag">定理</span><span class="mb-title">可导必连续</span><span class="mb-no">2.2</span></div>
          <div class="mb-body">
            若 \(f\) 在 \(x_0\) 可导，则 \(f\) 在 \(x_0\) 连续。
            <div class="proof-title">证明 · 3 步</div>
            <ol class="derive proof-body">
              <li><span class="derive-eq">把增量写成 \(\Delta y=\dfrac{\Delta y}{\Delta x}\cdot\Delta x\)（\(\Delta x\neq 0\)）</span><span class="derive-note">只是乘回去，没有取极限</span></li>
              <li><span class="derive-eq">令 \(\Delta x\to 0\)：第一项趋于 \(f'(x_0)\)，第二项趋于 \(0\)</span><span class="derive-note">可导保证第一个极限存在</span></li>
              <li><span class="derive-eq">\(\lim\limits_{\Delta x\to 0}\Delta y=f'(x_0)\cdot 0=0\)</span><span class="derive-note">这正是连续的定义，证毕</span></li>
            </ol>
          </div>
        </div>

        <div class="demo-box" data-demo="derivative-from-secant">
          <div class="demo-title">演示 1 · 割线滑向切线：差商怎样挤出一个数</div>
          <div class="demo-caption">拖动间距 \(h\)，第二个点沿抛物线滑向固定点。蓝线是曲线，橙线是过两点的割线，红色虚线是切线。<b>盯住读数里的割线斜率</b>：它等于 \(2+h\)，随着 \(h\) 变小一路挤到 2。注意整个过程中 \(h\) 一次都没有等于 0。</div>
        </div>

        <div class="math-block example">
          <div class="mb-head"><span class="mb-tag">例题</span><span class="mb-title">用定义求导数并写切线</span><span class="mb-no">例 2.1</span></div>
          <div class="mb-body">
            <div class="ex-part"><span class="ex-label">题目</span><span class="ex-q">设 \(f(x)=x^2-3x\)。用导数定义求 \(f'(2)\)，并写出曲线在 \(x=2\) 处的切线方程。</span></div>
            <div class="ex-part"><span class="ex-label">思路</span><span>先把 \(f(2+h)\) 和 \(f(2)\) 都算出来，作差、除以 \(h\)、化简，最后才让 \(h\to 0\)。切线用「点斜式」：过点 \((2,f(2))\)、斜率 \(f'(2)\)。</span></div>
            <div class="ex-part"><span class="ex-label">解</span><span>
              先算 \(f(2)=4-6=-2\)。<br>
              再算 \(f(2+h)=(2+h)^2-3(2+h)=4+4h+h^2-6-3h=-2+h+h^2\)。<br>
              于是 \(\Delta y=f(2+h)-f(2)=h+h^2\)，差商为 \(\dfrac{h+h^2}{h}=1+h\)（这里用到了 \(h\neq 0\)）。<br>
              取极限：\(f'(2)=\lim\limits_{h\to 0}(1+h)=1\)。<br>
              切线过点 \((2,-2)\)、斜率为 1，故 \(y-(-2)=1\cdot(x-2)\)，即 \(y=x-4\)。
            </span></div>
            <div class="ex-part"><span class="ex-label">评注</span><span class="ex-note">固定动作是「先展开、再约去 \(h\)、最后取极限」，顺序不能颠倒。凡是多项式，展开后一定能约掉 \(h\)；约不掉时就要回头检查是不是把 \(f(2+h)\) 算错了。</span></div>
          </div>
        </div>

        <div class="math-block insight">
          <div class="mb-head"><span class="mb-tag">直观理解</span><span class="mb-title">导数是割线斜率的极限位置</span></div>
          <div class="mb-body">差商 \(\dfrac{\Delta y}{\Delta x}\) 就是过曲线上两点的割线斜率。让第二点沿曲线滑向第一点，割线绕着固定点转，越来越贴近一条直线，那条直线的斜率就是导数。所以「可导」在图像上的意思是：<strong>曲线在那一点有一条确定的、不竖直的切线</strong>。</div>
        </div>

        <div class="math-block pitfall">
          <div class="mb-head"><span class="mb-tag">误区</span><span class="mb-title">把 0 直接代进差商</span></div>
          <div class="mb-body">差商 \(\dfrac{f(x_0+h)-f(x_0)}{h}\) 在 \(h=0\) 时是 \(\dfrac{0}{0}\)，没有意义。正确做法是先把它化简成在 \(h\neq 0\) 时成立的形式（如 \(1+h\)），再取极限。反过来，连续不一定可导：\(f(x)=|x|\) 在 \(x=0\) 连续，但左右差商分别趋于 \(-1\) 与 \(1\)，导数不存在。</div>
        </div>

        <h3><span class="sec-badge">2.2</span>函数的求导法则</h3>
        <p>每求一次导数都回到定义去算差商太慢了。把常见的组合方式各算一次极限，把结果记成法则，之后就能像搭积木一样组装。</p>

        <div class="math-block theorem">
          <div class="mb-head"><span class="mb-tag">定理</span><span class="mb-title">四则运算与链式法则</span><span class="mb-no">2.3</span></div>
          <div class="mb-body">
            设 \(u=u(x)\)、\(v=v(x)\) 都在 \(x\) 处可导，则
            $$(u\pm v)'=u'\pm v',\qquad (uv)'=u'v+uv',\qquad \left(\frac{u}{v}\right)'=\frac{u'v-uv'}{v^{2}}\ (v\neq 0)$$
            又设 \(y=F(u)\) 在 \(u\) 处可导、\(u=g(x)\) 在 \(x\) 处可导，则复合函数 \(y=F(g(x))\) 在 \(x\) 处可导，且
            $$\frac{\mathrm{d}y}{\mathrm{d}x}=F'(g(x))\,g'(x)$$
            <mark class="key">商法则要求分母不为零；链式法则不能漏乘内层导数 \(g'(x)\)</mark>。常用导数：\((x^{\mu})'=\mu x^{\mu-1}\)、\((\sin x)'=\cos x\)、\((\mathrm{e}^{x})'=\mathrm{e}^{x}\)、\((\ln x)'=\dfrac{1}{x}\ (x>0)\)。
          </div>
        </div>

        <div class="demo-box" data-demo="derivative-rules">
          <div class="demo-title">演示 2 · 法则算出来的导函数，真的等于切线斜率吗</div>
          <div class="demo-caption">蓝线是 \(f(x)=\dfrac{(x^{2}+1)^{2}}{8}\)，绿线是按链式法则算出的 \(f'(x)\)。拖动观察点 \(x_0\)，橙色切线贴着蓝线走，红点标出绿线在 \(x_0\) 处的读数。<b>两个数始终相等</b>——这就是法则与定义的一致性。</div>
        </div>

        <div class="math-block example">
          <div class="mb-head"><span class="mb-tag">例题</span><span class="mb-title">商法则里的定义域条件</span><span class="mb-no">例 2.2</span></div>
          <div class="mb-body">
            <div class="ex-part"><span class="ex-label">题目</span><span class="ex-q">设 \(f(x)=\dfrac{x^{2}+1}{x+2}\)。求 \(f'(x)\)，并说明公式在什么范围内有效。</span></div>
            <div class="ex-part"><span class="ex-label">思路</span><span>这是两个可导函数的商，用商法则。但先看清分母：\(x=-2\) 时函数根本没有定义，导数更无从谈起，这个条件要写在答案里。</span></div>
            <div class="ex-part"><span class="ex-label">解</span><span>
              记 \(u=x^{2}+1\)、\(v=x+2\)，则 \(u'=2x\)、\(v'=1\)，且在 \(x\neq -2\) 时 \(v\neq 0\)。<br>
              $$f'(x)=\frac{u'v-uv'}{v^{2}}=\frac{2x(x+2)-(x^{2}+1)\cdot 1}{(x+2)^{2}}=\frac{2x^{2}+4x-x^{2}-1}{(x+2)^{2}}=\frac{x^{2}+4x-1}{(x+2)^{2}}$$
              公式在 \(x\neq -2\) 时成立；\(x=-2\) 处 \(f\) 不连续，由「可导必连续」知不可导。
            </span></div>
            <div class="ex-part"><span class="ex-label">评注</span><span class="ex-note">用任何一条法则前，先把它的条件核对一遍：商的法则看分母、链式法则看内外层是否都可导、对数导数看真数是否为正。把「公式 + 适用范围」一起写出来，才算完整答案。</span></div>
          </div>
        </div>

        <div class="math-block insight">
          <div class="mb-head"><span class="mb-tag">直观理解</span><span class="mb-title">法则是算好的差商</span></div>
          <div class="mb-body">每一条法则都是「把差商极限提前算好一遍」的结果。链式法则之所以要多乘一个 \(g'(x)\)，是因为 \(x\) 变一点点时，中间变量 \(u\) 只变了 \(g'(x)\) 倍那么多，这个「传递倍率」必须算进去。</div>
        </div>

        <div class="math-block pitfall">
          <div class="mb-head"><span class="mb-tag">误区</span><span class="mb-title">链式法则漏乘内层导数</span></div>
          <div class="mb-body">求 \(\bigl((3x+1)^{4}\bigr)'\) 时写成 \(4(3x+1)^{3}\) 就漏了内层导数 3，正确结果是 \(12(3x+1)^{3}\)。固定动作：先认清「外层是谁、内层是谁」，写出来 \(F'(g(x))\cdot g'(x)\) 两个因子，再代入。</div>
        </div>

        <h3><span class="sec-badge">2.3</span>高阶导数</h3>
        <p>导函数本身也是一个函数，于是可以对它再求一次导。速度的变化率是加速度，斜率的变化率就告诉我们曲线往哪边弯。</p>

        <div class="math-block definition">
          <div class="mb-head"><span class="mb-tag">定义</span><span class="mb-title">二阶导数</span><span class="mb-no">2.4</span></div>
          <div class="mb-body">
            若导函数 \(f'\) 在 \(x\) 处仍可导，则称其导数为 \(f\) 在 \(x\) 的<strong class="term">二阶导数</strong>，记作 \(f''(x)\) 或 \(\dfrac{\mathrm{d}^{2}y}{\mathrm{d}x^{2}}\)。依次类推可得 \(n\) 阶导数 \(f^{(n)}(x)\)。
            <mark class="key">\(f''\) 存在的前提是 \(f'\) 在某邻域内有定义且可导</mark>。
          </div>
        </div>

        <div class="demo-box" data-demo="higher-derivatives">
          <div class="demo-title">演示 3 · 三条曲线：函数、斜率、斜率的变化率</div>
          <div class="demo-caption">蓝线是 \(f(x)=x^{3}-3x^{2}\)，绿线是 \(f'(x)=3x^{2}-6x\)，橙线是 \(f''(x)=6x-6\)。拖动观察点，读数同时给出三者在这一点的值。<b>看绿线穿过横轴的两处</b>：那里蓝线都走平（斜率为零），橙线在 \(x=0\) 取 \(-6\)、在 \(x=2\) 取 \(6\)，一负一正；橙线在 \(x=1\) 过零，蓝线弯的方向在那里改变。</div>
        </div>

        <div class="math-block example">
          <div class="mb-head"><span class="mb-tag">例题</span><span class="mb-title">求二阶导数并读出符号</span><span class="mb-no">例 2.3</span></div>
          <div class="mb-body">
            <div class="ex-part"><span class="ex-label">题目</span><span class="ex-q">设 \(f(x)=x^{3}-3x^{2}\)。求 \(f''(x)\)，并分别算出 \(x=0\) 与 \(x=2\) 处的 \(f''(x)\)，说明它们各表示什么。</span></div>
            <div class="ex-part"><span class="ex-label">思路</span><span>求两次导：先把 \(f\) 逐项求导得 \(f'\)，再对 \(f'\) 逐项求导得 \(f''\)。算完后代入两个具体点，把数字翻译成「斜率自己在怎么变」。</span></div>
            <div class="ex-part"><span class="ex-label">解</span><span>
              \(f'(x)=3x^{2}-6x\)，再求一次得 \(f''(x)=6x-6=6(x-1)\)。<br>
              \(f''(0)=-6\)：在 \(x=0\) 附近，斜率 \(f'\) 正以每单位约 6 的速度<strong>减小</strong>，曲线越走越平（相对切线往下偏）。<br>
              \(f''(2)=6\)：在 \(x=2\) 附近，斜率正以每单位约 6 的速度<strong>增大</strong>，曲线越走越陡（相对切线往上偏）。<br>
              当 \(x=1\) 时 \(f''(1)=0\)，斜率的变化率为零，曲线弯的方向在此处改变。
            </span></div>
            <div class="ex-part"><span class="ex-label">评注</span><span class="ex-note">二阶导数不是「再代一次公式」，而是把 \(f'\) 当成一个新函数重新求导。读到 \(f''\) 的符号时，问的永远是「\(f'\) 在增还是在减」，不要直接跳到「曲线向上还是向下」。</span></div>
          </div>
        </div>

        <div class="math-block insight">
          <div class="mb-head"><span class="mb-tag">直观理解</span><span class="mb-title">二阶导是斜率的斜率</span></div>
          <div class="mb-body">把 \(f'\) 想成「速度表读数」，\(f''\) 就是「速度表读数变化有多快」。\(f''>0\) 表示斜率在变大，\(f''&lt;0\) 表示斜率在变小，\(f''=0\) 只说明斜率此刻不变，还不能直接断定曲线怎么弯——这个判断留到下一章用中值定理补严。</div>
        </div>
=== SECTION:s4 ===
        <h3><span class="sec-badge">2.4</span>隐函数与参数方程确定的函数的导数、相关变化率</h3>
        <p>有时候 \(y\) 并没有被单独解出来，或者 \(x\) 与 \(y\) 都由第三个量 \(t\) 决定。这两种情形都不必先写出 \(y=f(x)\)，直接对等式两边求导就够了。</p>

        <div class="math-block definition">
          <div class="mb-head"><span class="mb-tag">定义</span><span class="mb-title">隐函数与参数方程的求导法</span><span class="mb-no">2.5</span></div>
          <div class="mb-body">
            <strong>隐函数</strong>：若方程 \(F(x,y)=0\) 在一段区间上确定了 \(y=y(x)\)，则把 \(y\) 看作 \(x\) 的函数，对等式两边关于 \(x\) 求导（遇到 \(y\) 时用链式法则乘上 \(y'\)），再解出 \(y'\)。<br>
            <strong>参数方程</strong>：若 \(x=\varphi(t)\)、\(y=\psi(t)\) 都可导且 \(\varphi'(t)\neq 0\)，则
            $$\frac{\mathrm{d}y}{\mathrm{d}x}=\frac{\psi'(t)}{\varphi'(t)}=\frac{\mathrm{d}y/\mathrm{d}t}{\mathrm{d}x/\mathrm{d}t}$$
            <mark class="key">\(\varphi'(t)\neq 0\) 是硬条件；等于 0 的点要单独讨论</mark>。
          </div>
        </div>

        <div class="demo-box" data-demo="implicit-and-parametric">
          <div class="demo-title">演示 4 · 参数曲线上的切线，以及公式失效的那一点</div>
          <div class="demo-caption">曲线由 \(x=t^{2}-1\)、\(y=t^{3}-t\) 给出。拖动参数 \(t\)，红点沿曲线走，橙色短线是该点切线。<b>把 \(t\) 拖到 0 附近</b>：读数会提示 \(\mathrm{d}x/\mathrm{d}t=0\)，此时 \(\dfrac{\mathrm{d}y/\mathrm{d}t}{\mathrm{d}x/\mathrm{d}t}\) 不能用，但曲线仍有自己的切线方向。</div>
        </div>

        <div class="math-block example">
          <div class="mb-head"><span class="mb-tag">例题</span><span class="mb-title">两问：隐函数与参数方程各练一次</span><span class="mb-no">例 2.4</span></div>
          <div class="mb-body">
            <div class="ex-part"><span class="ex-label">题目</span><span class="ex-q">(1) 设曲线由 \(x^{2}+xy+y^{2}=7\) 给出，求它在点 \((1,2)\) 处的切线斜率。(2) 设 \(x=t^{2}\)、\(y=t^{3}-t\)，求 \(t=2\) 处的 \(\dfrac{\mathrm{d}y}{\mathrm{d}x}\)。</span></div>
            <div class="ex-part"><span class="ex-label">思路</span><span>第 (1) 问先验证点在曲线上，再对等式两边求导、把含 \(y'\) 的项收拢到一边。第 (2) 问先检查 \(\mathrm{d}x/\mathrm{d}t\neq 0\)，再用参数方程公式。</span></div>
            <div class="ex-part"><span class="ex-label">解</span><span>
              (1) 代入得 \(1+2+4=7\)，点确实在曲线上。两边对 \(x\) 求导：<br>
              \(2x+\bigl(1\cdot y+x\cdot y'\bigr)+2y\,y'=0\)，这里 \(xy\) 用乘积法则、\(y^{2}\) 用链式法则。<br>
              整理：\((x+2y)y'=-(2x+y)\)，即 \(y'=-\dfrac{2x+y}{x+2y}\)。在 \((1,2)\) 处分母 \(1+4=5\neq 0\)，故斜率为 \(-\dfrac{2+2}{5}=-\dfrac{4}{5}\)。<br>
              (2) \(\varphi'(t)=2t\)、\(\psi'(t)=3t^{2}-1\)。\(t=2\) 时 \(\varphi'(2)=4\neq 0\)，可以用公式：
              $$\frac{\mathrm{d}y}{\mathrm{d}x}=\frac{3t^{2}-1}{2t}=\frac{12-1}{4}=\frac{11}{4}$$
            </span></div>
            <div class="ex-part"><span class="ex-label">评注</span><span class="ex-note">隐函数求导的固定动作是「把 \(y\) 当函数、逐项求导、再解一次方程」；参数方程的固定动作是「先算两个关于 \(t\) 的导数、再相除，并先检查分母」。两处都要显式检查分母不为零。</span></div>
          </div>
        </div>

        <div class="demo-box" data-demo="related-rates">
          <div class="demo-title">演示 5 · 两个量一起变：体积变化率怎么合成</div>
          <div class="demo-caption">圆柱半径 \(r(t)=2+0.2t\)、高 \(h(t)=5-0.1t\) 同时随时间变。拖动时刻 \(t\)，蓝线与绿线分别给出 \(r\) 与 \(h\)，读数把 \(\dfrac{\mathrm{d}V}{\mathrm{d}t}=\pi\left(2rh\dfrac{\mathrm{d}r}{\mathrm{d}t}+r^{2}\dfrac{\mathrm{d}h}{\mathrm{d}t}\right)\) 逐项算给你看。<b>关键是两项一正一负</b>：半径增大让体积变大，高减小让体积变小。</div>
        </div>

        <div class="math-block insight">
          <div class="mb-head"><span class="mb-tag">直观理解</span><span class="mb-title">相关变化率就是链式法则</span></div>
          <div class="mb-body">\(V\) 依赖 \(r\) 与 \(h\)，而 \(r\)、\(h\) 又都依赖 \(t\)，于是 \(V\) 通过两条路径受 \(t\) 影响，把两条路径各自算出的贡献加起来，就得到 \(\dfrac{\mathrm{d}V}{\mathrm{d}t}\)。演示里两项符号相反，正好说明「一个量变大」并不保证「总量变大」。</div>
        </div>

        <div class="math-block pitfall">
          <div class="mb-head"><span class="mb-tag">误区</span><span class="mb-title">在 \(\mathrm{d}x/\mathrm{d}t=0\) 处硬套公式</span></div>
          <div class="mb-body">参数方程公式的推导用到了「\(x\) 在局部可以反解成 \(t\) 的函数」，\(\varphi'(t)=0\) 时这一步不成立。遇到这种点要回到定义，分别看 \(\Delta y\) 与 \(\Delta x\) 的阶，或直接观察曲线在该点的走向。</div>
        </div>
=== SECTION:s5 ===
        <h3><span class="sec-badge">2.5</span>函数的微分</h3>
        <p>导数告诉我们「斜率」，微分则把这件事写成可以拿来算数的近似公式：曲线在小范围内几乎就是那条切线。</p>

        <div class="math-block definition">
          <div class="mb-head"><span class="mb-tag">定义</span><span class="mb-title">微分</span><span class="mb-no">2.6</span></div>
          <div class="mb-body">
            设 \(f\) 在 \(x\) 处可导。称
            $$\mathrm{d}y=f'(x)\,\mathrm{d}x$$
            为 \(f\) 在 \(x\) 处的<strong class="term">微分</strong>，其中自变量的微分 \(\mathrm{d}x\) 就取作增量 \(\Delta x\)。由可导性有
            $$\Delta y=f'(x)\,\Delta x+o(\Delta x)=\mathrm{d}y+o(\Delta x)$$
            <mark class="key">\(\mathrm{d}y\) 是 \(\Delta y\) 的线性主部，二者相差一个比 \(\Delta x\) 更高阶的无穷小</mark>。
          </div>
        </div>

        <div class="demo-box" data-demo="linear-approx">
          <div class="demo-title">演示 6 · 用切线代替曲线：近似值差多少</div>
          <div class="demo-caption">蓝线是 \(f(x)=\sqrt{x}\)，红色虚线是它在 \(x=4\) 处的切线 \(y=2+\dfrac{x-4}{4}\)。拖动增量 \(\Delta x\)，读数同时给出近似值、真实值和误差。<b>把 \(\Delta x\) 拖小，误差比 \(\Delta x\) 缩得更快</b>，这正是「高阶无穷小」的意思。</div>
        </div>

        <div class="math-block example">
          <div class="mb-head"><span class="mb-tag">例题</span><span class="mb-title">用微分估算一个平方根</span><span class="mb-no">例 2.5</span></div>
          <div class="mb-body">
            <div class="ex-part"><span class="ex-label">题目</span><span class="ex-q">不用计算器，用微分求 \(\sqrt{4.08}\) 的近似值，并估计这个近似值与真实值大约差多少。</span></div>
            <div class="ex-part"><span class="ex-label">思路</span><span>选一个「函数值好算、离 4.08 又很近」的基准点 \(x_0=4\)：那里 \(\sqrt{4}=2\) 是整数。取 \(f(x)=\sqrt{x}\)、\(\Delta x=0.08\)，用 \(\mathrm{d}y=f'(x_0)\Delta x\) 作为增量的近似。</span></div>
            <div class="ex-part"><span class="ex-label">解</span><span>
              \(f'(x)=\dfrac{1}{2\sqrt{x}}\)，故 \(f'(4)=\dfrac{1}{4}\)。<br>
              \(\mathrm{d}y=f'(4)\,\Delta x=\dfrac{1}{4}\times 0.08=0.02\)。<br>
              于是 \(\sqrt{4.08}\approx f(4)+\mathrm{d}y=2+0.02=2.02\)。<br>
              误差量级：\(\Delta y-\mathrm{d}y=o(\Delta x)\)。可直接验算 \(2.02^{2}=4.0804\)，比 4.08 大 \(0.0004\)。设真实值为 \(2.02-\varepsilon\)，则 \((2.02-\varepsilon)^{2}\approx 2.02^{2}-2\times 2.02\,\varepsilon\)，令它等于 4.08 得 \(0.0004\approx 4.04\,\varepsilon\)，即 \(\varepsilon\approx 0.0001\)，故真实值比 2.02 小约 \(0.0001\)。
            </span></div>
            <div class="ex-part"><span class="ex-label">评注</span><span class="ex-note">固定动作是「挑基准点 → 算 \(f(x_0)\) 与 \(f'(x_0)\) → 乘上 \(\Delta x\)」。基准点要选函数值和导数都好算的地方，\(\Delta x\) 越小近似越好；误差是比 \(\Delta x\) 更高阶的无穷小，所以 \(\Delta x\) 缩小 10 倍，误差大约缩小 100 倍。</span></div>
          </div>
        </div>

        <div class="math-block insight">
          <div class="mb-head"><span class="mb-tag">直观理解</span><span class="mb-title">微分就是局部线性化</span></div>
          <div class="mb-body">把曲线不断放大，任何可导函数在足够小的范围内看起来都像一条直线，那条直线就是切线。微分把「像」变成「可以用」：用直线的增量 \(\mathrm{d}y\) 代替曲线的增量 \(\Delta y\)，代价是丢掉一个高阶小量。</div>
        </div>

        <div class="math-block pitfall">
          <div class="mb-head"><span class="mb-tag">误区</span><span class="mb-title">把 \(\mathrm{d}y\) 当成 \(\Delta y\)</span></div>
          <div class="mb-body">\(\mathrm{d}y\) 只是 \(\Delta y\) 的线性主部，两者并不相等。写 \(\Delta y=\mathrm{d}y\) 会丢掉 \(o(\Delta x)\)，只在 \(\Delta x=0\) 时才是零误差。需要精确值时必须用 \(f(x_0+\Delta x)-f(x_0)\) 真算；用微分只能说「近似」并交代误差量级。</div>
        </div>
=== PITFALLS ===
      <div class="math-block pitfall">
        <div class="mb-head"><span class="mb-tag">误区</span><span class="mb-title">把 0 直接代进差商</span></div>
        <div class="mb-body"><b>错误做法</b>：在 \(\dfrac{f(x_0+h)-f(x_0)}{h}\) 里令 \(h=0\) 得到 \(\dfrac{0}{0}\)，就说导数不存在。<b>为什么错</b>：差商只对 \(h\neq 0\) 有定义，导数研究的是 \(h\to 0\) 时的趋势，不是 \(h=0\) 处的值。<b>正确做法</b>：先在 \(h\neq 0\) 下化简差商，再取极限；化简后若左右极限不同（如 \(|x|\) 在 0 处）才判定不可导。</div>
      </div>
      <div class="math-block pitfall">
        <div class="mb-head"><span class="mb-tag">误区</span><span class="mb-title">链式法则漏乘内层导数</span></div>
        <div class="mb-body"><b>错误做法</b>：\(\bigl((3x+1)^{4}\bigr)'=4(3x+1)^{3}\)。<b>为什么错</b>：外层对中间变量求导后，还必须乘上中间变量对 \(x\) 的变化倍率 3。<b>正确做法</b>：写成 \(4(3x+1)^{3}\cdot 3=12(3x+1)^{3}\)，先分层再相乘。</div>
      </div>
      <div class="math-block pitfall">
        <div class="mb-head"><span class="mb-tag">误区</span><span class="mb-title">隐函数求导时把 \(y\) 当常数</span></div>
        <div class="mb-body"><b>错误做法</b>：对 \(x^{2}+xy+y^{2}=7\) 求导得到 \(2x+y=0\)。<b>为什么错</b>：\(y\) 是 \(x\) 的函数，\(y^{2}\) 求导要乘 \(y'\)，\(xy\) 要用乘积法则。<b>正确做法</b>：逐项写成 \(2x+(y+xy')+2yy'=0\)，再把含 \(y'\) 的项收拢求解。</div>
      </div>
      <div class="math-block pitfall">
        <div class="mb-head"><span class="mb-tag">误区</span><span class="mb-title">把 \(\mathrm{d}y\) 与 \(\Delta y\) 混为一谈</span></div>
        <div class="mb-body"><b>错误做法</b>：用 \(\sqrt{4.08}\approx 2.02\) 时声称「结果精确等于 2.02」。<b>为什么错</b>：\(\Delta y=\mathrm{d}y+o(\Delta x)\)，丢掉的高阶小量虽小但不为零（真实值约 2.0199）。<b>正确做法</b>：写明是近似，并用平方回代或高阶项估计误差量级。</div>
      </div>

=== SUMMARY ===
      <p>这一章只做了一件事：把第 1 章的「取极限」用在差商 \(\dfrac{\Delta y}{\Delta x}\) 上，得到导数。定义给出斜率，四则运算与链式法则让计算变快，高阶导数把斜率本身再求一次导，隐函数与参数方程把「解不出 \(y\)」的情形也纳入，微分则把切线变成可算的近似公式。</p>
      <p>但还有一个缺口：我们知道 \(f'(x)\) 是「某一点的斜率」，却还不会用它在一段区间上推断函数的整体行为。下一章的微分中值定理会补上这座桥——它把一点处的导数与一段区间上的增量联系起来，单调性、极值与最值才有严格依据。</p>

      figureHint: '三条曲线共用同一条竖线：蓝线的值、绿线的斜率、橙线的斜率变化率。'
    });
  },

  'implicit-and-parametric': function (el) {
    const X = t => t * t - 1, Y = t => t * t * t - t;
    const dX = t => 2 * t, dY = t => 3 * t * t - 1;
    DemoPresets.custom(el, {
      range: [-2.5, 2.5, -2.5, 2.5], boxH: 380,
      slider: { label: '参数', min: -1.2, max: 1.2, step: 0.01, init: 1.0 },
      figureHint: '把 t 拖到 0 附近，观察读数里关于分母为零的提示。',
      draw: (p, out, t, c, C) => {
        let prev = null;
        for (let i = 0; i <= 400; i++) {
          const u = -1.9 + 3.8 * i / 400, q = [X(u), Y(u)];
          if (prev) p.line(prev[0], prev[1], q[0], q[1], { color: C('accent'), width: 2.4 });
          prev = q;
        }
        const k = dY(t) / dX(t);
        if (Number.isFinite(k)) {
          p.line(-2.4, k * (-2.4 - X(t)) + Y(t), 2.4, k * (2.4 - X(t)) + Y(t),
            { color: C('warn'), width: 1.8 });
        }
        p.dot(X(t), Y(t), { r: 5, color: C('danger') });
        const ok = Math.abs(dX(t)) > 1e-6;
        out.innerHTML = `${texHTML('t=' + f4(t))}：${texHTML('\\mathrm{d}x/\\mathrm{d}t=' + f4(dX(t)))}，${texHTML('\\mathrm{d}y/\\mathrm{d}t=' + f4(dY(t)))}<br>` +
          (ok
            ? `因为分母不为零，可用 ${texHTML('\\dfrac{\\mathrm{d}y}{\\mathrm{d}x}=\\dfrac{3t^{2}-1}{2t}=' + f4(k))}，橙色短线就是该点切线。`
            : `此时 ${texHTML('\\mathrm{d}x/\\mathrm{d}t=0')}，参数方程公式的分母为零，不能相除；曲线在该点仍有走向，需另作讨论。`);
      }
    });
  },

  'related-rates': function (el) {
    const r = t => 2 + 0.2 * t, h = t => 5 - 0.1 * t;
    const dr = 0.2, dh = -0.1;
    DemoPresets.sliderCurve(el, {
      range: [0, 8, 0, 6], boxH: 360,
      slider: { label: '时刻', min: 0, max: 8, step: 0.05, init: 0 },
      hint: '半径与高度同时变化，体积变化率是两项之和',
      curves: [
        { fn: r, color: 'accent', width: 2.4 },
        { fn: h, color: 'ok', width: 2.4 }
      ],
      dynamic: (p, t, C) => {
        p.line(t, 0, t, 6, { color: C('cyan'), dash: true, width: 1.2 });
        p.dot(t, r(t), { r: 5, color: C('accent') });
        p.dot(t, h(t), { r: 5, color: C('ok') });
      },
      readout: (t) => {
        const A = 2 * r(t) * dr * h(t), B = r(t) * r(t) * dh;
        return `在 ${texHTML('t=' + f4(t))} 时：${texHTML('r=' + f4(r(t)))}、${texHTML('h=' + f4(h(t)))}。<br>` +
          `${texHTML('2rh\\,\\mathrm{d}r/\\mathrm{d}t=' + f4(A))}（半径增大，正贡献），${texHTML('r^{2}\\,\\mathrm{d}h/\\mathrm{d}t=' + f4(B))}（高度减小，负贡献）。<br>` +
          `合计 ${texHTML('\\dfrac{\\mathrm{d}V}{\\mathrm{d}t}=\\pi(' + f4(A) + f4(B) + ')=' + f4(Math.PI * (A + B)))}。`;
      },
      figureHint: '两条变化率一正一负，必须分别算出再相加。'
    });
  },

  'linear-approx': function (el) {
    const f = x => Math.sqrt(x), x0 = 4;
    DemoPresets.sliderCurve(el, {
      range: [3, 5.5, 1.5, 2.6], boxH: 360,
      slider: { label: '增量', min: 0, max: 0.5, step: 0.005, init: 0.08 },
      hint: '把增量拖小，比较近似值与真实值',
      curves: [
        { fn: f, color: 'accent', width: 2.6 },
        { fn: x => 2 + (x - 4) / 4, color: 'danger', dash: true, width: 1.8 }
      ],
      dynamic: (p, dx, C) => {
        const x = x0 + dx;
        p.line(x, 1.5, x, f(x), { color: C('cyan'), dash: true, width: 1.2 });
        p.dot(x, f(x), { r: 5, color: C('accent') });
        p.dot(x, 2 + dx / 4, { r: 5, color: C('warn') });
      },
      readout: (dx) => {
        const real = f(x0 + dx), approx = 2 + dx / 4;
        return `${texHTML('\\Delta x=' + f4(dx))}：微分给出 ${texHTML('\\mathrm{d}y=\\dfrac{\\Delta x}{4}=' + f4(dx / 4))}，近似值 ${texHTML(f4(approx))}，真实值 ${texHTML(f4(real))}。<br>` +
          `误差 ${texHTML(f4(Math.abs(real - approx)))}；把 ${texHTML('\\Delta x')} 缩小 10 倍，误差大约缩小 100 倍，因为丢掉的是 ${texHTML('o(\\Delta x)')}。`;
      },
      figureHint: '红点是切线给出的近似，蓝点是曲线上的真实值；两点几乎重合。'
    });
  }
};

mountDemos(DEMOS);
